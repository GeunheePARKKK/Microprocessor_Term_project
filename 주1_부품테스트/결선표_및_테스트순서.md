# 주 1 : 결선표 + 부품별 테스트

EVB 는 키트 소켓에 꽂고 키트 외부 전원(PWR-JACK)을 켠다. GND 는 공통이라 따로 안 꽂는다.

## 1. 결선표

| 기능 | EVB 핀 |
|---|---|
| FND 세그먼트 A ~ G | PTD1 ~ PTD7 |
| FND 자릿수 CM1 ~ CM4 | PTD8 ~ PTD11 |
| 키패드 ROW1 ~ 4 | PTE0, PTE1, PTE2, PTE3 |
| 키패드 COL1 ~ 3 | PTE12, PTE14, PTE15 |
| 스텝모터 IN1 ~ IN4 | PTB8, PTB9, PTB10, PTB11 |
| 초음파 TRIG | PTC16 |
| 초음파 ECHO | PTC17 |
| 비상 버튼 SW1 | PTC8 |
| 모드 / 해제 버튼 SW2 | PTC9 |
| 부저 | PTD12 |
| 차량 감지 LED0 | PTE8 |
| 경고 LED1 | PTE9 |
| OLED SCL | PTA3 |
| OLED SDA | PTA2 |
| UART (OpenSDA USB, 결선 없음) | PTC6, PTC7 |

### 1-1. FND 11가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J18-1 ~ 7 | SEG_A ~ G | PTD1 ~ PTD7 |
| J19-1 ~ 4 | CM1 ~ CM4 | PTD8 ~ PTD11 |

### 1-2. 키패드 7가닥 (핀 번호 순서대로가 아님)

| 키패드 핀 | 역할 | EVB 핀 |
|---|---|---|
| 1 | COL2 (2 5 8 0) | PTE14 |
| 2 | ROW1 (1 2 3) | PTE0 |
| 3 | COL1 (1 4 7 *) | PTE12 |
| 4 | ROW4 (* 0 #) | PTE3 |
| 5 | COL3 (3 6 9 #) | PTE15 |
| 6 | ROW3 (7 8 9) | PTE2 |
| 7 | ROW2 (4 5 6) | PTE1 |
| 8 | 안 씀 | |

### 1-3. 스위치 · LED · 부저 5가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J13-1 | SW1 (누르면 0) | PTC8 |
| J13-2 | SW2 | PTC9 |
| J16-1 | LED0 (0 = ON) | PTE8 |
| J16-2 | LED1 (0 = ON) | PTE9 |
| J17 BUZZER | 부저 (1 = ON) | PTD12 |

### 1-4. 스텝모터 · 초음파 6가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J20-1 ~ 4 | ST_IN1 ~ 4 | PTB8 ~ PTB11 |
| J27-3 (또는 4) | UW_TRIG | PTC16 |
| J27-1 (또는 2) | UW_ECHO | PTC17 |

모터 커넥터는 J22. 초음파 센서는 키트에 붙어 있음. J27 은 1 · 2 = ECHO, 3 · 4 = TRIG.

### 1-5. OLED 2가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J34-1 (또는 2) | SCL | PTA3 |
| J34-3 (또는 4) | SDA | PTA2 |

OLED 모듈은 U8 에 꽂혀 있음. 0.91" (128x32) 모듈이면 oled.h 의 `OLED_HEIGHT` 를 32 로.

## 3. PuTTY (UART 로그 보기)

1. https://www.putty.org 에서 64-bit x86 installer 받아 설치.
2. EVB 를 USB 로 PC 에 연결. 장치 관리자 → 포트(COM & LPT) → "OpenSDA - CDC Serial Port (COMx)" 의 번호 확인.
3. PuTTY 실행 → Connection type **Serial**, Serial line **COMx**, Speed **9600** → Open.
4. 보드 리셋 버튼을 누르면 창에 로그가 찍힌다. 안 찍히면 COM 번호와 9600 확인.
