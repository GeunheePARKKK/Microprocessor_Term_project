# 텀프로젝트 주 1 : 결선 확정 + 부품별 단독 테스트

작성 2026-11-18. 계획서 `텀프로젝트_스마트주차차단기_베어메탈_vs_RTOS_계획.md` 2절의 "핀 (안)" 을 부록04(키트 회로도) · 부록09(EVB 회로도) 로 확인해 확정한 표다.

## 1. 확정 결선표

EVB 는 키트 소켓에 꽂고, 키트 외부 전원(PWR-JACK) 을 켠다. GND 는 공통이라 따로 안 꽂는다.

| 기능 | EVB 핀 |
|---|---|
| FND 세그먼트 A ~ G | PTD1 ~ PTD7 |
| FND 자릿수 CM1 ~ CM4 | PTD8 ~ PTD11 |
| 키패드 ROW1 ~ 4 | PTE0, PTE1, PTE2, PTE3 |
| 키패드 COL1 ~ 3 | PTE12, PTE14, PTE15 |
| 스텝모터 IN1 ~ IN4 | PTB8, PTB9, PTB10, PTB11 |
| 초음파 TRIG | PTC16 |
| 초음파 ECHO | PTC17 |
| 비상 버튼 SW1 | PTC8 |
| 모드 / 해제 버튼 SW2 | PTC9 |
| 부저 | PTD12 |
| 열림 표시 LED0 | PTE8 |
| 경고 LED1 | PTE9 |
| OLED SCL | PTA3 |
| OLED SDA | PTA2 |
| UART 로그 (OpenSDA, 결선 없음) | PTC6 RX, PTC7 TX |
| 측정용 토글 핀 (주 2 이후) | PTE16 |
| (2순위) Text LCD | PORTB 여분 (PTB0 ~ 5, 12 ~ 17) |

점퍼 수 : FND 11 + 키패드 7 + 스텝모터 4 + 초음파 2 + 버튼 2 + 부저 1 + LED 2 + OLED 2 = **31 가닥**.

### 1-1. FND 11가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J18-1 ~ 7 | SEG_A ~ G | PTD1 ~ PTD7 |
| J19-1 ~ 4 | COM (CM1 ~ CM4) | PTD8 ~ PTD11 |

### 1-2. 키패드 7가닥 (키패드 헤더 핀 번호가 순서대로가 아님에 주의)

| 키패드 핀 | 역할 | EVB 핀 |
|---|---|---|
| 1 | COL2 (가운데 세로줄 2 5 8 0) | PTE14 |
| 2 | ROW1 (가로줄 1 2 3) | PTE0 |
| 3 | COL1 (왼쪽 세로줄 1 4 7 *) | PTE12 |
| 4 | ROW4 (가로줄 * 0 #) | PTE3 |
| 5 | COL3 (오른쪽 세로줄 3 6 9 #) | PTE15 |
| 6 | ROW3 (가로줄 7 8 9) | PTE2 |
| 7 | ROW2 (가로줄 4 5 6) | PTE1 |
| 8 | 안 씀 | |

1 → PTE12, 2 → PTE14 … 식으로 차례대로 꽂으면 숫자가 뒤바뀌고 `#` 이 `*` 로 읽힌다 (2026-11-18 실제로 겪음).

### 1-3. 스위치 · LED · 부저 5가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J13-1 | SW1 (비상, 누르면 0) | PTC8 |
| J13-2 | SW2 (모드 / 해제) | PTC9 |
| J16-1 | LED0 (0 = ON) | PTE8 |
| J16-2 | LED1 (0 = ON) | PTE9 |
| J17 BUZZER 핀 | 부저 (1 = ON) | PTD12 |

### 1-4. 스텝모터 · 초음파 6가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J20-1 | ST_IN1 | PTB8 |
| J20-2 | ST_IN2 | PTB9 |
| J20-3 | ST_IN3 | PTB10 |
| J20-4 | ST_IN4 | PTB11 |
| J27-3 또는 4 | UW_TRIG (트리거 출력) | PTC16 |
| J27-1 또는 2 | UW_ECHO (에코 입력) | PTC17 |

점퍼 외에 : 스텝모터 5핀 커넥터를 J22 에 꽂고, 키트 외부 전원(PWR-JACK)을 켠다. 초음파 센서는 키트에 이미 붙어 있다.
J27 은 4핀 중 1 · 2 번이 UW_ECHO, 3 · 4 번이 UW_TRIG 로 둘씩 묶여 있다. TRIG · ECHO 를 거꾸로 꽂으면 거리가 항상 ---- 로 나온다.
선배 팀(2024F 4조)은 같은 센서를 TRIG PTE0 · ECHO PTE1 로 써서 동작 확인했으므로 키트 분압(3.3 V) 그대로 읽어도 된다.

### 1-5. OLED 2가닥

| 키트 헤더 | 역할 | EVB 핀 |
|---|---|---|
| J34-1 또는 2 | SCL (I2C 클럭) | PTA3 |
| J34-3 또는 4 | SDA (I2C 데이터) | PTA2 |

OLED 모듈은 키트 OLED(I2C) 칸의 U8 소켓에 꽂혀 있다. 풀업 저항은 모듈에 있다.
주소는 0x3C 가 기본이고 안 되면 코드가 0x3D 를 자동으로 시도한다. 모듈이 0.91" 128x32 면 oled.h 의 OLED_HEIGHT 를 32 로 바꾼다.

### 1-6. 배선 진행 기록

- 2026-11-18 : FND 11 + 키패드 7 + 스위치 2 + LED 2 + 부저 1 = 23가닥으로 test4 전체 동작 확인.
- 2026-11-25 : 스텝모터 4 추가, main_test_all 로 키패드 · FND · 부저 · LED · 스텝모터 동작 확인. 초음파는 ---- 만 나옴 (미해결). OLED 는 코드만 작성, 보드 미확인.

## 2. 코드 파일

| 파일 | 내용 |
|---|---|
| `tp_board.h` / `tp_board.c` | 모든 핀의 PORT 설정, LPIT 딜레이, DWT 사이클 카운터, FND, 키패드, 부저 · LED · 스위치 매크로, UART, 스텝모터, 초음파. 주 2 의 ① 순차 루프에서 그대로 쓴다 |
| `oled.h` / `oled.c` | 키트 OLED(SSD1306, I2C) 드라이버 : LPI2C0 (PTA2 SDA, PTA3 SCL) 약 100 kHz, 6x8 글꼴 8행 x 21열 |
| `main_test1_stepper.c` | **스텝모터만** (4가닥). 90° 올라갔다 1 s 쉬고 내려오기 반복 |
| `main_test2_ultrasonic.c` | **초음파만** (TRIG · ECHO + LED0 = 3가닥). 100 ms 마다 측정, 20 cm 이내면 키트 LED0 ON. EVB 자체 LED 초록 = 에코 정상, 빨강 = 에코 없음(배선 · 센서 문제) |
| `main_test3_uart_dwt.c` | **배선 없음**. UART 출력 확인 + DWT 로 delay · Seg_out · KeyScan · UART 20 글자의 시간을 재서 PC 로 출력 (측정 루틴 검증, 계획서 1-2 표의 실제값) |
| `main_test4_io.c` | FND · 키패드 · SW · LED · 부저 (23가닥). 키패드 → FND, `*` 지우기, `#` 부저, SW1 → LED1, SW2 → LED0. 결선 종합 검사 |
| `main_test5_oled.c` | **OLED 만** (2가닥). 제목, 0.5 s 카운터, 글꼴 줄, 자라는 막대. EVB 자체 LED 초록 = 통신 OK, 빨강 = 응답 없음 |
| `main_test_all.c` | test4 + test1 + test2 통합 (29가닥). 숫자/`*` 는 test4 와 같고, `#` = 삑 + 차단기 올렸다 내리기(SW1 비상, SW2 해제), 초음파 100 ms 마다 측정해 20 cm 이내 LED0, SW2 누르고 있으면 FND 에 거리(cm). 주 2 의 출발점 |

S32DS 프로젝트에는 `tp_board.c`, `tp_board.h`, `clocks_and_modes.c/.h`(기존 것) 를 넣고 (OLED 쓰면 `oled.c`, `oled.h` 도), `main_test*.c` 중 **하나만** `main.c` 로 이름을 바꿔 src 에 둔다 (둘 이상 있으면 main 중복 링크 오류).
코드 주석은 S32DS 에서 한글이 깨지므로 영문(ASCII)만 쓴다.

## 3. 테스트 순서와 통과 기준

각 test 는 그 부품만 꽂으면 된다. 쓰는 가닥은 1-1 ~ 1-5 소표의 해당 줄.

1. **test1_stepper** (1-4 의 J20 4가닥 + 모터 J22). 모터가 약 1 초 동안 한쪽으로 90° 돌고, 1 초 쉬고, 반대로 돌아온다. 떨리거나 안 돌면 J20 순서(IN1 → IN4) 와 키트 외부 전원을 확인.
2. **test2_ultrasonic** (1-4 의 J27 2가닥 + 1-3 의 LED0 1가닥). 손을 센서 앞 20 cm 안에 대면 키트 LED0 이 켜진다. EVB 자체 RGB LED 가 초록이면 에코가 들어오는 것, 빨강이면 에코가 전혀 없는 것(배선 · 센서 확인). PuTTY 가 있으면 cm 숫자도 보인다.
3. **test5_oled** (1-5 의 2가닥). 화면 1행에 "SMART PARKING v0.1", 카운터와 맨 아랫줄 막대가 0.5 초마다 바뀌면 통과. EVB 자체 LED 가 빨강이면 I2C 응답 없음(SCL · SDA 바뀌었는지, 모듈이 U8 에 꽂혔는지 확인).
4. **test3_uart_dwt** (배선 없음). PuTTY 를 OpenSDA COM 포트, 9600 으로 열고 리셋. "TP week1 UART OK" 와 측정표가 나오면 통과. 숫자를 계획서 1-2 표 옆에 적어 둔다 (delay_ms(1) 이 약 1000 us 면 DWT 가 맞는 것).
5. **test4_io** (1-1 ~ 1-3 의 23가닥). 키패드 1 ~ 9, 0 이 FND 에 밀려 들어오고, `*` 로 0000, `#` 누르는 동안 부저. SW1 누르면 LED1, SW2 누르면 LED0. 안 되는 것이 있으면 그 줄의 점퍼만 다시 본다.
6. **test_all** (29가닥, 전부). 주 2 통합 전 마지막 확인.

## 4. 주의

- 스텝모터 시퀀스는 2상 여자 풀스텝 4단계(IN1·2 → IN2·3 → IN3·4 → IN4·1). 28BYJ-48 은 풀스텝 한 바퀴 2048 스텝이라 90° = 512 스텝, 2 ms/스텝이면 1.02 초.
- 초음파 ECHO 대기는 ① 순차 구조의 "긴 작업" 이므로 일부러 폴링으로 두고 30 ms 타임아웃만 넣었다. 측정 간격은 60 ms 이상(HC-SR04 요구).
- delay_us / delay_ms 는 LPIT ch0 폴링이다. 주 3 에서 LPIT ch0 을 1 ms 인터럽트로 쓰면 delay 는 ch2 로 옮긴다.
- UART 는 LPUART1 을 SOSCDIV2 8 MHz 로 돌린다. clocks_and_modes.c 의 SOSC_init_8MHz 가 SOSCDIV2 = 1 로 켜 두므로 추가 설정 없음.
- 부저는 6주차에 PTD11 이었으나 FND COM 과 겹쳐 PTD12 로 옮겼다.
