# 텀프로젝트 주 1 : 결선 확정 + 부품별 단독 테스트

작성 2026-11-18. 계획서 `텀프로젝트_스마트주차차단기_베어메탈_vs_RTOS_계획.md` 2절의 "핀 (안)" 을 부록04(키트 회로도) · 부록09(EVB 회로도) 로 확인해 확정한 표다.
키트 보드의 J1 ~ J6 헤더는 EVB 의 J1 ~ J6 과 핀 배치가 같다 (부록04 1쪽 "MAIN B'd CONN"). 아래 "헤더 핀" 은 그 번호다.

## 1. 확정 결선표

EVB 는 키트 소켓에 꽂고, 키트 외부 전원(PWR-JACK) 을 켠다. GND 는 공통이라 따로 안 꽂는다.
"키트 부품 헤더" 와 "EVB 헤더 핀" 사이를 점퍼선으로 잇는다.

| 기능 | 키트 부품 헤더 | 신호 | EVB 핀 | EVB 헤더 핀 | 방향 · 설정 | 비고 |
|---|---|---|---|---|---|---|
| FND 세그먼트 A ~ G | J18-1 ~ 7 | SEG_A ~ G | PTD1 ~ PTD7 | J6-02, J6-03, J6-04, J4-01, J1-12, J5-18, J5-16 | 출력, 1 = ON | 5 ~ 11주차 그대로 |
| FND 자릿수 CM1 ~ CM4 | J19-1 ~ 4 | SEG_COM6 ~ 3 | PTD8 ~ PTD11 | J6-07, J6-05, J1-06, J1-08 | 출력, 1 = 선택 | 5 ~ 11주차 그대로 |
| 키패드 ROW1 ~ 4 | 키패드 핀 2, 7, 6, 4 | ROW | PTE0, PTE1, PTE2, PTE3 | J3-06, J5-14, J4-13, J1-16 | 입력, 내부 풀다운 | 6주차 그대로 |

| 초음파 TRIG | J27 의 UW_TRIG 핀 | UW_TRIG | PTC16 | J6-08 | 출력, 10 us 펄스 | 센서 모듈은 J26 에 꽂음 |

| 모드 / 해제 버튼 | J13-2 | SW2 | PTC9 | J6-11 | 입력 | |

| 열림 표시 LED | J16-1 | LED0 (470 Ω, 0 = ON) | PTE8 | J2-08 | 출력 | |
| 경고 LED | J16-2 | LED1 | PTE9 | J3-08 | 출력 | |
| UART 로그 | 없음 | OpenSDA 가상 COM | PTC6 RX, PTC7 TX | 결선 없음 | ALT2 | PC 에서 PuTTY, 9600 8N1 |
| 측정용 토글 핀 | 없음 (스코프 프로브) | | PTE16 | J5-02 | 출력 | 주 2 이후 |
| (2순위) Text LCD | J15 / J14 | RS, RW, EN, D4 ~ D7 | PORTB 여분 (PTB0 ~ 5, 12 ~ 17) | J4-05, J4-07, J2-11, J2-09, J2-07, J2-05 … | | 11주차 lcd1602A.c 의 BASE 를 바꿔야 함. 주 5 |

중복 확인 결과: 위 핀 중 EVB 내장 부품(RGB LED PTD0 · 15 · 16, 버튼 PTC12 · 13, 가변저항 PTC14, UART PTC6 · 7)과 겹치는 것은 없다. PTD3 은 J6-04 와 J1-14 두 곳에 나오는데 같은 선이라 아무 쪽이나 쓴다.

점퍼 수 : FND 11 + 키패드 7 + 스텝모터 4 + 초음파 2 + 버튼 2 + 부저 1 + LED 2 = **29 가닥**.

## 4. 테스트 순서와 통과 기준

1. **test4_io 먼저** (결선 검사). 키패드 1 ~ 9, 0 이 FND 에 밀려 들어오고, `*` 로 0000, `#` 누르는 동안 부저. SW1 누르면 LED1, SW2 누르면 LED0. 안 되는 것이 있으면 그 줄의 점퍼만 다시 본다.
2. **test3_uart_dwt**. PuTTY 를 OpenSDA COM 포트, 9600 으로 열고 리셋. "TP week1 UART OK" 와 측정표가 나오면 통과. 숫자를 계획서 1-2 표 옆에 적어 둔다 (delay_ms(1) 이 약 1000 us 면 DWT 가 맞는 것).
3. **test1_stepper**. 모터가 약 1 초 동안 한쪽으로 90° 돌고, 1 초 쉬고, 반대로 돌아온다. 떨리거나 안 돌면 J20 순서(IN1 → IN4) 와 키트 외부 전원을 확인. SW1 을 누르면 그 자리에서 멈추고 부저가 울린다. SW2 로 해제.
4. **test2_ultrasonic**. 손을 센서 앞에서 움직이면 FND 숫자(cm)가 따라 바뀌고, 20 cm 이내에서 LED0 이 켜진다. 범위 밖이면 "----". PuTTY 에도 같은 값이 찍힌다.

## 5. 주의

- 스텝모터 시퀀스는 2상 여자 풀스텝 4단계(IN1·2 → IN2·3 → IN3·4 → IN4·1). 28BYJ-48 은 풀스텝 한 바퀴 2048 스텝이라 90° = 512 스텝, 2 ms/스텝이면 1.02 초.
- 초음파 ECHO 대기는 ① 순차 구조의 "긴 작업" 이므로 일부러 폴링으로 두고 30 ms 타임아웃만 넣었다. 측정 간격은 60 ms 이상(HC-SR04 요구).
- delay_us / delay_ms 는 LPIT ch0 폴링이다. 주 3 에서 LPIT ch0 을 1 ms 인터럽트로 쓰면 delay 는 ch2 로 옮긴다.
- UART 는 LPUART1 을 SOSCDIV2 8 MHz 로 돌린다. clocks_and_modes.c 의 SOSC_init_8MHz 가 SOSCDIV2 = 1 로 켜 두므로 추가 설정 없음.

| `main_test_all.c` | test4 + test1 + test2 한 번에. 숫자/`*` 는 test4 와 같고, `#` = 삑 + 차단기 올렸다 내리기(SW1 비상, SW2 해제), 초음파 100 ms 마다 측정해 20 cm 이내 LED0, SW2 누르고 있으면 FND 에 거리(cm) |
