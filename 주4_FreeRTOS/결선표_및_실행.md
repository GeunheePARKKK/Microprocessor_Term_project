# 주 4 : ③ FreeRTOS 구조

## 1. 결선표

주 2 와 같다 (29가닥 + 측정 점퍼 1 + OLED 2). `주2_시스템_1차완성/결선표_및_동작설명.md` 1절.

## 2. FreeRTOS 커널 넣기

1. https://github.com/FreeRTOS/FreeRTOS-Kernel → Releases → 최신 zip 받아 풀기.
2. S32DS 프로젝트 안에 `FreeRTOS` 폴더를 만들고 아래만 복사.

| 복사할 것 | 위치 |
|---|---|
| `include/` 폴더 전체 | `FreeRTOS/include/` |
| `tasks.c`, `queue.c`, `list.c` | `FreeRTOS/` |
| `portable/GCC/ARM_CM4F/port.c`, `portmacro.h` | `FreeRTOS/portable/GCC/ARM_CM4F/` |
| `portable/MemMang/heap_4.c` | `FreeRTOS/portable/MemMang/` |

3. 프로젝트 우클릭 → Properties → C/C++ Build → Settings → Standard S32DS C Compiler → Includes 에 추가 :
   `${ProjDirPath}/FreeRTOS/include`, `${ProjDirPath}/FreeRTOS/portable/GCC/ARM_CM4F`, `${ProjDirPath}/src`
4. `src` 에 `main.c`, `tp_board.c/.h`, `clocks_and_modes.c/.h`, `FreeRTOSConfig.h` (+ `oled.c/.h`).
5. startup 파일은 손대지 않는다. `FreeRTOSConfig.h` 가 SVC · PendSV 를 startup 의 핸들러 이름에 연결하고, SysTick 은 main.c 에 있다.
6. 빌드가 안 되면 : `FreeRTOS.h` 못 찾음 → 3번 경로. `SVC_Handler` 중복 정의 → startup 의 것이 weak 가 아닌 경우이므로 startup 쪽 정의를 지운다.

S32 SDK 가 깔려 있으면 `S32SDK_S32K1xx_RTM_x.x.x/rtos/FreeRTOS` 에 같은 파일이 있다.

## 3. 코드 파일

`tp_board`, `oled` 는 주 3 과 같은 파일.

| main.c 스위치 | 값 |
|---|---|
| `USE_OLED` | 0 / 1 |
| `MEASURE` | 0 시스템, 1 스트레스 (R1 ~ R5, M2, M3), 2 M1 측정 |
| `DUMMY_TASKS` | 0 / 3 / 6 (M4) |
| `FND_MODE` | 0 FND 태스크 (1 ms 틱), 1 FND 를 LPIT 인터럽트로 (10 ms 틱일 때) |
| `M1_CYCLES` | `MEASURE 2` 결과를 적어 두면 `MEASURE 1` 보고서에 M3 가 계산됨 |
| `PRIO_*` | 태스크 우선순위 (조건 변수) |

| FreeRTOSConfig.h | 값 |
|---|---|
| `TP_TICK_HZ` | 1000 (1 ms) / 100 (10 ms, 이때 `FND_MODE 1`) |
| `configUSE_PREEMPTION` | 1 / 0 |

## 4. 태스크

| 태스크 | 우선순위 | 주기 / 깨우는 것 | 하는 일 |
|---|---|---|---|
| T_Safety | 5 | SW1 인터럽트의 세마포어 | 모터 정지, 부저, EMERGENCY 이벤트 |
| T_FND | 4 | 1 ms | 자리 하나 |
| T_Motor | 3 | 2 ms | 1 스텝 |
| T_Sensor | 2 | 100 ms | TRIG, ECHO 세마포어 대기 (35 ms 까지), DIST 이벤트 |
| T_Keypad | 2 | 20 ms | 키 스캔, KEY 이벤트 |
| T_Logic | 2 | 이벤트 큐 | 상태기계, 모터 명령, 로그 큐 |
| T_Log | 1 | 로그 큐 | UART 출력 (자기만 막힘) |
| T_Dummy | 1 | 항상 | 계산 루프 (M4 용) |

## 5. 측정 순서

1. `MEASURE 2` 빌드 → PuTTY 의 `M1 = ... cycles` 를 main.c `M1_CYCLES` 에 적는다. M2 도 같이 나온다.
2. `MEASURE 1` 빌드 (PTC8 의 SW1 선 대신 PTE16 점퍼) → R1 ~ R5, M2, M3 → 계획서 5절 표 ③ 열.
3. `DUMMY_TASKS` 3, 6 으로 2번 반복 → M4.
4. 조건 변수 : `TP_TICK_HZ 100` + `FND_MODE 1`, `PRIO_FND 1`, `PRIO_MOTOR 1`, `configUSE_PREEMPTION 0` 각각 2번 반복 → 계획서 4-4 표.
