# 주 2 보완 : 센서 고장 대응 (① 순차 루프)

`주2_시스템_1차완성` 은 그대로 두고, 고친 버전을 이 폴더에 따로 둔다.
S32DS 프로젝트 = 이 폴더의 `main.c` + `tp_board.c/.h` + `clocks_and_modes.c/.h` (+ `oled.c/.h`). 결선은 주 2 와 같다 (추가 결선 없음).

## 1. 왜

1차 버전은 초음파가 응답을 안 하면 거리 0 → "차 없음" 으로 처리했다.
11-25 에 실제로 센서 불량(키트 교체로 해결)을 겪었는데, 그 상태로 시스템을 돌리면 **차가 밑에 있어도 차단기가 내려온다.**

## 2. 바뀐 동작

초음파 결과를 셋으로 나눈다 (`tp_board.h`).

| 값 | 뜻 | 판단 |
|---|---|---|
| `US_NO_ECHO` (0) | 30 ms 안에 에코가 아예 안 옴 | 센서가 응답 안 함 → 계속되면 고장 |
| `US_OUT_OF_RANGE` (9999) | 에코는 왔지만 30 ms 안에 안 끝남 | 앞에 아무것도 없음 (정상) |
| 1 ~ 약 500 | 거리 cm | 20 cm 이하면 차 있음 |

`US_NO_ECHO` 가 **10번 연속 (1 초)** 이면 `SENSOR FAULT`.

| | 고장 중 | 
|---|---|
| 표시 | EVB 빨간 LED 켜짐 (결선 없음, test2 와 같은 LED), UART `SENSOR FAULT` |
| OPEN | 안 내려감 (차가 있다고 보고 기다림) |
| CLOSING | 즉시 멈춤 → EMERGENCY. SW2 로 해제하면 OPEN 으로 가서 기다림 |
| INPUT | 2 초 지나도 IDLE 로 안 돌아감 |
| IDLE | 새 차 감지 안 함 (그대로 대기) |

응답이 한 번이라도 다시 오면 빨간 LED 꺼짐, `SENSOR OK again`, 정상 동작.

## 3. 그 밖에

- PTE16 을 **HIGH 로 시작** (`tp_board.c`). 측정 점퍼(PTE16 → PTC8)를 꽂은 채 `MEASURE 0` 으로 돌려도 비상 정지가 안 걸린다.
- `MEASURE 1` 보고서 R5 줄에 `sensor answered N / M` 추가 (측정 중 센서가 응답한 횟수).
- 측정 타이밍은 1차 버전과 같다 (타임아웃 30 ms 그대로). 측정 모드에서는 고장 판정이 상태에 영향을 안 준다.

## 4. 확인 방법

1. `MEASURE 0` 으로 빌드, 평소처럼 동작하는지 (1차 버전 확인 순서 그대로).
2. 차단기를 연 상태(OPEN)에서 **초음파 ECHO 선(PTC17)을 뽑는다** → 1 초 뒤 빨간 LED + `SENSOR FAULT`, 손을 치워도 안 내려감.
3. 선을 다시 꽂는다 → 빨간 LED 꺼짐, 손 없으면 2 초 뒤 내려감.
4. 내려가는 중에 ECHO 선을 뽑는다 → 1 초 안에 멈춤 + 부저. SW2 → OPEN 으로 대기.
