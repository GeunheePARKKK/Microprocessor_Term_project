# 주 3 : ② 인터럽트 베어메탈 구조

## 1. 결선표

주 2 와 같다 (29가닥 + 측정 점퍼 1 + OLED 2). `주2_시스템_1차완성/결선표_및_동작설명.md` 1절.

## 2. 코드 파일

S32DS 프로젝트 = `main.c` + `tp_board.c/.h` + `clocks_and_modes.c/.h` (+ `oled.c/.h`).
`tp_board` 는 주 1 · 2 것과 **다른 파일**이다 (인터럽트용). 주 4 와는 같다.

| main.c 스위치 | 0 | 1 |
|---|---|---|
| `USE_OLED` | OLED 안 씀 | 상태 · 거리 · 자리 수 표시 |
| `MEASURE` | 시스템 동작 | 스트레스 측정 100 회 → PuTTY 에 결과표 |

## 3. 주 2 와 다른 점

| 일 | 주 2 (①) | 주 3 (②) |
|---|---|---|
| FND 자리 전환 | 루프에서 Seg_out 4 ms 블로킹 | LPIT 1 ms 인터럽트에서 자리 하나 |
| 모터 1 스텝 | 루프 1바퀴에 1 스텝 (4 ~ 30 ms) | 1 ms 인터럽트에서 2 ms 마다 |
| 키패드 | 루프에서 3 ms 블로킹 | 20 ms 플래그 → 메인에서 150 us 스캔 |
| 초음파 | 루프에서 에코 폴링 (최대 30 ms 블로킹) | 100 ms 마다 인터럽트에서 TRIG, ECHO 에지 인터럽트로 거리 계산 |
| 비상 버튼 | 루프 끝에서 읽음 | PORTC 인터럽트에서 즉시 모터 정지 |
| UART | 블로킹 (20 글자 21 ms) | 큐에 넣고 루프마다 1 글자 (안 막힘) |
| 삑 3번 | delay_ms 600 ms 블로킹 | 비블로킹 |

인터럽트 우선순위 : PORTC (SW1 · ECHO) 1, LPIT 2.

## 4. 측정 (`MEASURE 1`)

주 2 와 같은 절차 (PTE16 → PTC8 점퍼, 100 회, 약 1 분). R1 은 PTE16 하강 → PORTC 인터럽트 안의 `Stepper_release()`. 결과는 계획서 5절 표 ② 열.
